# Literature Search Workflow

## Sources

- OpenAlex
- Semantic Scholar
- DBLP
- IEEE Xplore
- ACM Digital Library
- CNKI
- arXiv

## Strategy

Combine:

1. Keyword search
2. Citation expansion
3. Author expansion
4. Venue filtering
5. Recent trend analysis

## Metadata Collection

Each paper should record:

- Title
- Authors
- Year
- Venue
- Keywords
- Main contribution
- Limitations
- Research category
- Citation information
