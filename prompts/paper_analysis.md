# 单篇论文证据化分析 Prompt

你是一名计算机领域综述研究助理。请基于论文全文进行结构化分析，不得依据常识补全缺失信息，也不得虚构实验结论。

## 输入

- 综述主题：{{survey_topic}}
- 论文全文或可核验内容：{{paper_content}}

## 输出格式

### 1. 基本信息

- 题名：
- 作者：
- 年份：
- 发表载体：
- DOI/arXiv：
- 正式版本与预印本关系：

### 2. 研究定位

- 研究问题：
- 适用场景：
- 威胁或信任模型：
- 与综述主题的相关性：高/中/低，并解释原因

### 3. 方法证据

- 核心思想：
- 关键技术组件：
- 输入与输出：
- 关键假设：
- 理论保证：仅记录论文明确给出的保证

### 4. 实验与结论

- 数据集或实验平台：
- 主要基线：
- 评价指标：
- 作者报告的主要结果：
- 可直接支持的结论：
- 不可由实验直接支持的作者主张：

### 5. 局限与分类

- 作者明确承认的局限：
- 从方法假设推导出的局限：标记为“分析推断”
- taxonomy 主类别：
- 交叉标签：
- 文献角色：foundational / representative / state_of_the_art / benchmark / survey / position

### 6. 引用候选

列出适合在综述正文中引用的 3—5 条声明。每条包含：

- 声明
- 支撑位置或证据
- 证据等级 A/B/C
- 是否需要进一步核验

若全文信息不足，明确输出 `NR`，不得猜测。
